# WiFi Fingerprinting Project for Indoor Localization and Floor Detection

This repository contains the implementation code, dataset setup, and visual results for indoor localization and floor classification using WiFi fingerprinting techniques (Received Signal Strength Indicator — RSSI).

## Project Overview
- **Floor Detection:** Multi-class classification to predict the target floor level from AP RSSI vectors.
- **Positioning / Localization:** Regression / spatial estimation ($X, Y$ coordinates) within the target environment.
